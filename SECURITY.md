# Security

Do not report credential leaks or other sensitive vulnerabilities in a public issue.

For security concerns, contact the Medux team through the support channel shown on [medux.io](https://medux.io). Include only the information needed to reproduce the issue and remove API keys, signed URLs, private media, and personal data from logs or screenshots.

If you accidentally commit a Medux API key, revoke it immediately in your account and create a replacement. Removing it from the latest commit is not sufficient because it may remain in Git history and caches.
